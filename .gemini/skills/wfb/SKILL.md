# WFB (Workflow Builder)

Create and iteratively improve workflow skills, SOPs, and Gate scripts from retro findings or user requests.

Read and follow [SOP.md](SOP.md) in this directory.

## Invariants
- Never modify, copy, or wrap any **IP Skill** (`GLOSSARY.md`).
- Never write skill/SOP edits without explicit human approval of the diff plan.
- Keep `SKILL.md` <= 30 lines; keep all process steps inside `SOP.md`.
